WhatsApp Meta Cloud Deployment Skill

Reusable agent skill for ASP.NET Core + Meta WhatsApp Business Cloud API
Version 1.0 | Extracted from Millennium EA / Ticketing System integration

1. Purpose

Teaches an AI coding agent (or developer) how to deploy the same WhatsApp bot architecture to any ASP.NET Core backend.

Use when: New client WhatsApp bot, redeployment, Meta webhook integration, interactive list menus, phone-based user verification.

2. Product behavior (Shuru / KRA model)

WhenWhoWhat happens
Any message (idle)EveryoneWelcome text + "View Services" interactive menu
User picks a serviceUnregistered"Register on portal first, then message again"
User picks a serviceRegisteredService runs with real UserId + Role
Mid-flowRegisteredContinue flow — no welcome spam
Key rule: The bot is open to everyone. Registration gates actions, not greetings.

  4. Verify Token must match appsettings

8. Conversation logic order

  1. Invalid phone → error
  2. HumanHandoff → agent chat / end chat
  3. AwaitingAgentIssue → start handoff
  4. AwaitingNewTicketDescription → create ticket
  5. AwaitingTicketId → show status
  6. "end chat" → welcome + menu
  7. Service action → registration gate → service
  8. Default → welcome + menu

10. Registration gate pattern

var user = await _userResolver.ResolveByWhatsAppPhoneAsync(fromPhone, ct);
if (user is null) {
    await _sender.SendRegistrationRequiredMessageAsync(fromPhone, ct);
    return;
}
SetState(phone, nextStep, user.Id, user.Role);
